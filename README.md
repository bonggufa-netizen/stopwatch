# 피자 프랜차이즈 9개 매장 실적 분석

피자 프랜차이즈 9개 매장의 2020-01~2026-10 월별 실적(실습용 가상 데이터)을 탐색적으로 분석하고, 경영진 보고용 슬라이드와 CEO 대시보드로 정리한 저장소입니다.

## 핵심 시사점

분석 기준: 매출데이터 4,428행을 매장·월 738건으로 중복 제거하고, 2026-09~10 추정치를 뺀 실적 720건(2020-01~2026-08)을 사용했습니다. 2026년은 1~8월을 2025년 1~8월과 비교했습니다. 원인은 사건로그로 확인된 것(확인)과 데이터로 추론한 것(추정)을 나눴습니다.

| # | 시사점 | 근거 |
|---|---|---|
| 1 | 매출 성장은 객단가가 끌었고, 주문 수는 2022년 이후 정체 | 2022→2025 매출 +17%, 주문 −1%, 객단가 +19% |
| 2 | 영업이익률은 2022년 18.0%가 정점, 이후 하락분은 인건비 상승으로 설명됨 | 인건비율 24.5%(2020) → 29.0%(2026) |
| 3 | 자사앱은 6배 성장했지만 외부 배달앱 의존도는 43%에서 그대로 | 외부앱 주문 1건당 수수료 +21% (배민 수수료 인상, EV-024) |
| 4 | 2026년 체인 이익률은 올랐지만 충장로점·연동점만 후퇴, 공통 원인은 인력 이탈 | 점주 승계(EV-029), 정규직 연속 퇴사(EV-025·035) |
| 5 | 위생·QSC 점수가 고객 반응을 설명하지 못함 | 위생 B 등급 달 50%, QSC~클레임 상관 0.06 |

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `피자_CEO_대시보드.html` | CEO 대시보드 단일 파일 (데이터 포함, 브라우저로 바로 열림. 차트 라이브러리 d3는 인터넷에서 불러옴) |
| `피자 매장별 실적 데이터.xlsx` | 원본 데이터 (매출데이터, 사건로그, 마스터 시트 등 10개 시트) |
| `slides/` | 16:9 슬라이드 덱 9장 소스 (`deck.json`, `deck.css`, `slides/*.html`). `preview.html`은 전체 슬라이드를 한 페이지로 묶은 미리보기 |
| `dashboard/` | CEO 대시보드 페이지(`index.html`)와 정리된 데이터(`store_month.json` 매장·월 738건, `events.json` 사건 39건) |
| `scripts/` | 분석에 쓴 PowerShell 스크립트 |

## 재현 방법 (Windows PowerShell)

스크립트는 저장소 안의 `work/` 폴더(커밋하지 않음)에 중간 결과를 씁니다.

1. 엑셀 파일을 압축 해제합니다: `Copy-Item '피자 매장별 실적 데이터.xlsx' work\data.zip; Expand-Archive work\data.zip work\x`
2. 시트를 CSV로 변환합니다: `scripts\tocsv.ps1 work\x work\csv`
3. 매장·월 단위로 중복 제거합니다: `scripts\sm.ps1` → `work\sm.csv`
4. 집계를 실행합니다: `scripts\eda.ps1`, `scripts\eda3.ps1`
5. 대시보드 데이터를 만듭니다: `scripts\prep_dash.ps1` → `work\dashdata\*.json`

한글이 든 스크립트는 UTF-8(BOM)으로 저장되어 있어야 Windows PowerShell 5.1에서 제대로 읽힙니다.
