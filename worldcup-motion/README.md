# 월드컵 키네틱 타이포그래피 모션그래픽

바우하우스 스타일(빨강·노랑·파랑 원색, 원·삼각형·사각형)의 월드컵 응원 모션그래픽입니다. 외부 라이브러리 없이 HTML 파일 하나로 동작합니다.

| 파일 | 내용 |
|---|---|
| `worldcup2030_kinetic_1920x1080.mp4` | 완성 영상 (16:9, 1920×1080, 60fps, 30초, 소리 포함) |
| `worldcup2030_kinetic_16x9.html` | 30초 16:9 버전 원본. 2030 → 100년 타임라인 → 대~한민국 → 손흥민(7) 골 → 이강인(18) 프리킥 골 → 오 필승 코리아 → 엔딩 |
| `worldcup_kinetic.html` | 10초 9:16 세로 버전 |

## 사용법

1. HTML 파일을 Chrome이나 Edge에서 엽니다.
2. **▶ 소리와 함께 재생**으로 미리 봅니다.
3. **● 영상으로 저장**을 누르면 MP4로 저장됩니다. 30초 버전은 프레임 단위로 인코딩(WebCodecs)하므로 PC 속도와 관계없이 끊김 없는 파일이 나옵니다.

## 참고

- 경기장 함성, 구호, 박수, 휘슬 등 소리는 모두 Web Audio로 합성했습니다.
- '오 필승 코리아'는 저작권이 있는 곡이라 멜로디는 넣지 않았고, 관중 구호 리듬으로만 표현했습니다.
- 선수는 실제 사진이나 영상 없이 도형 캐릭터와 이름·등번호로 표현한 팬 응원용 그래픽입니다.
